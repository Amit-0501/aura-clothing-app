# AURA Studio 🌿

A fully functional single-page clothing store built with **React 18**, **Vite 5**, and **Tailwind CSS 3**. Features a dark editorial aesthetic with a live cart, category filters, sliding cart drawer, and product modal previews.

---

## Features

- 🛒 **Cart State** — Add, remove, and update item quantities. Subtotal calculated in real-time.
- 🏷️ **Category Filters** — Filter by Tops, Bottoms, Outerwear, or Essentials.
- ↕️ **Price Sorting** — Sort by Featured, Price Low → High, or Price High → Low.
- 🛍️ **Sliding Cart Drawer** — Slides in from the right with a free-shipping progress bar.
- 🔍 **Product Modal** — Click any card for a full preview with size selection and add-to-cart.
- 📦 **8 Seeded Products** — Real clothing photos from Unsplash across all 4 categories.
